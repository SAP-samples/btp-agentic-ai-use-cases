### Important Notes
- If the workflow uses an AI Agent node or MCP Server node, declare the dependency in `requires`. Otherwise `requires` may be omitted.
- `provides.apis[]` entries and `workflow.ordId` **MUST** be generated by the script in the execution skill — do not invent these values manually.

### Example
#### Example 1: Multi-Asset Solution (Agent + n8n Workflows)

All n8n workflow assets live under `assets/workflows/`. Each workflow gets its own subfolder with its own `asset.yaml`. The n8n asset type is declared inside `metadata.type` as `n8nworkflow`.

```yaml
# solution.yaml
apiVersion: solution.sap/v1
kind: Solution
metadata:
  name: invoice-approval-3a9f2
  version: "1.0.0"
  description: "Invoice approval with AI agent and n8n workflows"
assets:
  - ref: ./assets/invoice-approval-agent/asset.yaml
  - ref: ./assets/workflows/morning-email-workflow/asset.yaml
  - ref: ./assets/workflows/conditional-email-routing-workflow/asset.yaml
```

```yaml
# assets/workflows/morning-email-workflow/asset.yaml
apiVersion: asset.sap/v1
kind: Asset

metadata:
  name: morning-email-workflow
  description: Sends the morning email digest
  version: "1.0.0"
  type: n8nworkflow

projectVersion: "1"
sourceRoot: "."

workflow:
  definitionFile: morning-email.n8n.json
  name: morning-email-workflow
  ordId: sap.btpn8n:apiResource:ManagedN8nMcpServer:v1

requires:
  - name: invoice-approval-agent
    kind: agent
    ordId: customer.build:agent:invoice-approval-3a9f2.invoice-approval-agent:v1

provides:
  apis:
    - name: send_morning_email
      path: /invoice-approval-3a9f2/morning-email-workflow/send-morning-email
      kind: rest
      description: Triggers the morning email dispatch workflow
      ordId: sap.n8nwfrt:apiResource:invoice-approval-3a9f2_morning-email-workflow.sendMorningEmail:v1
    - name: send_morning_email_mcp_server
      kind: mcp-server
      description: MCP server for morning email workflow operations
      ordId: sap.n8nwfrt:apiResource:invoice-approval-3a9f2_morning-email-workflow.sendMorningEmailMcpServer:v1
```

> `sourceRoot: "."` means `definitionFile` is resolved relative to `assets/workflows/morning-email-workflow/`. The workflow file is therefore at `assets/workflows/morning-email-workflow/morning-email.n8n.json`.

> Each webhook node in the workflow produces **two** entries under `provides.apis[]`: one with `kind: rest` (the HTTP endpoint) and one with `kind: mcp-server` (the MCP translation). Both are generated by the script — do not write them manually.

The folder structure for this solution:
```
solution.yaml
assets/
├── invoice-approval-agent/
│   ├── asset.yaml
│   └── ...
└── workflows/
    ├── morning-email-workflow/
    │   ├── asset.yaml
    │   └── morning-email.n8n.json
    └── conditional-email-routing-workflow/
        ├── asset.yaml
        └── conditional-email-routing.n8n.json
```
